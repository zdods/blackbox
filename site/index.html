get started view source

$ curl -fsSL https://raw.githubusercontent.com/zdods/blackbox/main/install.sh | sh

why blackbox

yours, entirely

Single-user by design. Your files stay on your machines — no third-party storage, no telemetry, no accounts but your own.

any machine

Daemons run on Linux, macOS, and Windows. One static binary each, installed with a single command or Homebrew.

one console

Browse, upload, download, and preview files on every connected host from a fast web console — desktop or phone.

locked down

Password + TOTP two-factor login, httpOnly sessions, TLS end-to-end, and owner-read-only daemon configs.

boring stack

Go standard library, Postgres, WebSockets. Ships as a signed multi-arch container with SBOM and provenance attestation.

open source

MIT licensed. Read the code, run it forever, file issues, send patches.

how it works

run the server

docker compose up pulls the prebuilt image. Register once — that's your account.

connect a daemon

Add a host in the console, run the daemon with the copied token, and point it at a directory.

browse everything

Every connected machine shows up in one place. Upload, download, preview, delete.
