There is no cloud. Only someone else's hard drive.

blackhaul turns the computers you already own into a "cloud" that's actually yours — browse, upload, and download from one secure dashboard, while your files never leave home.

Get started View on GitHub

Install in seconds

$ curl -fsSL https://raw.githubusercontent.com/zdods/blackhaul/main/install.sh | sh

Paste this into the terminal on any machine you want to reach. That's the whole install.

What you get

Line by line. No asterisks.

01

[▪‿▪] Your files stay home

blackhaul never copies your data to anyone else's hardware. The server in the middle just passes files through without keeping anything — your stuff lives on your machines and nowhere else. No tracking, ever.

02

[▪ω▪] Works with what you own

A laptop, an old desktop, a NAS, the server in your closet — blackhaul runs a tiny helper program (the daemon) quietly in the background on Linux, macOS, and Windows. One command installs it.

03

[▪o▪] Everything in one console

Browse, upload, download, and preview files on all of your machines from one clean web dashboard that works just as well on your phone.

04

[–‿–] No network gymnastics

Your machines call out to the server — nothing on the internet can call in. No router settings, no VPN, no port forwarding, no asking your ISP for anything. If it can browse the web, it can join.

05

[▪_▪] Secure by default

Two-factor login is part of setup, not an optional extra. Everything travels over the same kind of encryption your bank uses, end to end.

06

[^‿^] Open source

Free and open source (MIT), built on boring, proven technology. Anyone can read the code, run it forever, and help shape where it goes.

How it keeps you safe

Locked down, not locked in. The boring kind of secure — the kind you stop thinking about.

  • Two-factor from the first login. Linking an authenticator app is part of signing up — not an optional extra you forget to turn on.
  • Nothing to break into. Your machines only ever call out, so there's no door on them for the internet to knock on.
  • Encrypted the whole way. Browser to server, server to your machines — the same encryption your bank uses (TLS), end to end.
  • Careful with your keys. One click logs you out everywhere, and access tokens are stored scrambled — never as plain text.
  • Downloads you can trust. Every release is cryptographically signed, so you can check it really came from us, untouched.
  • A real way to report problems. Found something? Tell us quietly via SECURITY.md and we'll fix it loudly.
