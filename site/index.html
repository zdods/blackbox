Private cloud storage on hardware you already own. blackbox links your computers to a single secure console — browse, upload, and download from anywhere, while your files never leave your machines.

Why blackbox

Your files stay home

blackbox never copies your data to someone else's cloud. The server only relays — file content lives on your machines and nowhere else. No telemetry, ever.

Works with what you own

A laptop, a NAS, the server in your closet — a small background service (the blackbox daemon) runs on Linux, macOS, and Windows. One binary, installed with a single command or Homebrew.

Everything in one console

Browse, upload, download, and preview files on all of your machines from a clean web console that works just as well on your phone.

No network gymnastics

Your machines connect outward to the server, so you never open a port, configure a VPN, or touch your router. If it can reach the internet, it can join.

Secure by default

Two-factor authentication is built in, not bolted on. TLS end-to-end, hardened sessions, rate-limited logins, and signed releases you can verify.

Open source

MIT licensed with a deliberately simple foundation — Go, PostgreSQL, WebSockets. Read the code, run it forever, help shape the roadmap.

How it works

Run the server

One docker compose up on any box you trust pulls the prebuilt image. Register once — the account is yours alone.

Connect your machines

Add a host in the console, run the daemon with the token it hands you, and choose which folder to share.

Browse everything

Every connected machine appears in one place. Upload, download, preview, and manage your files from anywhere.
